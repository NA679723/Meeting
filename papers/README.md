# Shared PDFs

Put PDFs here, then point to them from `data/papers.json`:

```json
"pdf": "papers/kunzel2019-metalearners.pdf"
```

PDFs stored here open in a viewer on the site. Links to other sites (arXiv, a journal) open in a new tab.

Only upload files the group is allowed to share. On a public repository, anything in this folder can be downloaded by anyone. For paywalled papers, link to the publisher or an arXiv version, or use a private shared folder (set `sharedFolderUrl` in `data/config.json`).
